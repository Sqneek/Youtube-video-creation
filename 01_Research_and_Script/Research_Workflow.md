# Research Instructions

## Source priority
1. Academic/historian books, peer-reviewed articles
2. Long-form documentaries/channels with cited sources
3. Museum/university/archive sites
4. Encyclopedic sources (Britannica) — cross-check only, never sole source
5. News/pop-history — lowest trust, angle-spotting only

Every load-bearing fact (dates, figures, quotes, causal claims) traces to a tier 1–3 source.

## Notes file
Create `Videos/[Topic_Name]/Research_Notes.md`:
- Core question / hook angle
- Timeline: date — event — source
- Key people: name — role — vivid fact
- Disputed points: both sides
- Visual reference notes: location/person/object — visual detail — source
- Sources: [Title](URL)

## Rules
- Cross-check every date/figure against 2+ independent sources
- Flag single-source facts as unverified — drop or mark disputed
- Verify spelling of names, places, titles
- Paraphrase only — never copy source sentences into notes
- Capture visual details (architecture, dress, objects) for anything that will recur on screen
